# Guided onboarding

## A useful first conversation

Use the short goal question in SKILL.md only when the seller has not already named a task. Accept ordinary language such as “nothing is selling” and suggest the relevant workflow. Match the owner's language for guidance and reports; customer replies follow the customer's written language.

Collect context progressively, not as a long form before doing anything:

1. For account work: marketplace, shop identity and authenticated access through the host's supported tools. Never request a password, cookie or token in chat.
2. For catalogue work: inventory source, exact product/unit and whether to prepare, save drafts or publish. Reuse established authority.
3. For design: approved style/reference, exact packaging, gallery count and source/generation policy. Prepare a sample first if the style is unknown.
4. For growth: the goal, available stock, current prices/costs, permitted free actions and any exact paid budget.
5. For recurring work: timezone, staffed hours, cadence, notification rules and an available persistent scheduler.

Proceed with useful read-only analysis while optional facts are pending. Ask one concise bundle for facts that actually block the next action. Summarise a blocker by product, missing fact, what can proceed, and the smallest owner answer. Do not repeatedly request permission for existing authorised work.

## Recommended routes

| Seller says | Start here | Useful next question if missing |
|---|---|---|
| “Set everything up” | Coordinator: inspect context, then inventory and customer operations | Which shop/marketplace and inventory source? |
| “Upload these” | Posting + inventory; design for missing approved assets | Draft only or publish when verified? |
| “Use our photo template” | Design | Where is the approved reference and exact pack photo? |
| “Why no sales?” | Report, then growth | Which dates and goal: traffic, orders or contribution? |
| “Bump more” | Bump | Any mandatory products and approved hours? |
| “Run ads for a small amount” | Growth/ads: prepare one concrete plan | Exact total ceiling and duration, if not already supplied? |
| “Handle the shop daily” | Coordinator: operations, scheduler, reporting | Staffed hours and which replies/actions may be sent? |

## Finish onboarding

Create or update the private operating file using [setup and permissions](setup-and-permissions.md). Record unresolved fields as unknown. Confirm the immediate plan briefly, including any owner-specified limits. Installation does not create schedules, enable messaging, authorise spending, or connect an account. Report actual tool limitations and continue independent preparation.
