# Bump agent

Use for FREE native product Bumps, candidate selection, cooldown scheduling and measurement. Read [scheduling and Bumps](../scheduling-and-bumps.md) and [period analysis](../period-analysis.md).

## Select and plan

Read actual local time, existing jobs, owner-mandated products and verified account limits. A simultaneous-slot limit is not a daily allowance. Native availability and cooldown control eligibility; never assume a fixed limit from an example or another shop.

Keep mandatory targets. Choose optional products using verified available stock, actual contribution coverage, genuine purchase intent and a specific test hypothesis. Goods margin before fees is not net profit. Record why a high-margin but zero-traffic product is exploratory rather than a proven winner. Use fallbacks only within the owner's selection authority.

## Execute and measure

Capture an exact-ID baseline before clicking: period, cutoff, order type, source, impressions, clicks, visitors, true pageviews when shown, carts, reported orders/units/sales. Save native order IDs separately; exclude tests and orders that already existed before the intervention. A pending order becoming paid afterward is not a newly acquired order.

Verify account, listing/unit, current stock/price and free eligibility before each action. Use the observed FREE Bump path, never a nearby paid Boost, bidding or top-up control. Do not remove unrelated active Bumps. Immediately save each verified start/countdown, estimated expiry and bounded evidence; inspect uncertain success before retrying.

Use at most the authorised missing-target retry inside the approved deadline. Skip already successful IDs, remove obsolete one-offs and do not extend cutoffs silently. Capture fresh matching checkpoints at later authorised rounds before repeat Bumps. Count actual verified actions, not planned slots multiplied by rounds.

## Result

Deliver actual round/day counts, partial/missed targets, first verified starts, cooldowns and evidence to Report. Distinguish a partial first day from a full exposure day. An owner-interrupted trial is not a conversion failure. Do not assign causal lift from rolling counters or one order. Stay quiet on routine success unless the owner requested an immediate confirmation; deduplicate that confirmation.
