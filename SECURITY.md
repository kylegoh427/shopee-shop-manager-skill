# Security policy

Do not post credentials, cookies, customer conversations, addresses, private shop exports or exploitable secrets in a public issue. Private vulnerability reporting is enabled for this repository: use [Report a vulnerability](https://github.com/kylegoh427/shopee-shop-manager-skill/security/advisories/new). If that channel is unavailable, ask the maintainer for a private channel using a short, non-sensitive description. Other copies of this skill do not automatically inherit these repository settings.

Include the affected release/commit, a synthetic reproduction, expected/observed behaviour and impact. We do not need live seller access or your password to review a report. There is no guaranteed response-time promise.

The portable [security and privacy guide](skills/shopee-shop-manager/references/security-and-privacy.md) explains offline helper capabilities, authorised tool transmissions, review/integrity checks, safe updates and their limitations. A passing test, checksum or MIT licence is not security certification.
